## 2024-05-13 - [Fast Filter Logic]\n**Learning:** In React, applying a `.toLowerCase()` call inside a `.filter()` iteration that runs on every render with a large dataset (like the inventory) causes significant performance degradation due to redundant object creation and string evaluation.\n**Action:** If search terms are involved, pre-calculate their lower-case version before the `.filter()` loop, or use simple checks if acceptable.
