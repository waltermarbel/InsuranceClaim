## 2025-03-08 - Array Allocations in React useMemo Hooks
**Learning:** Chaining multiple `.filter()` operations consecutively inside React `useMemo` hooks allocates a new array in memory for each step. Given the core architecture of VeritasVault managing large datasets of inventory items on the client-side, this creates significant performance regressions and memory pressure on re-renders, further exacerbated by stale closures when dependency arrays are incomplete.
**Action:** Always use single-pass iteration with short-circuit return logic (e.g., returning `false` early within a single `.filter()` call) when processing large collections inside `useMemo`. This ensures O(n) complexity and O(1) array allocation overhead. Additionally, rigorously verify hook dependency completeness as the existing linting setup does not enforce this.
