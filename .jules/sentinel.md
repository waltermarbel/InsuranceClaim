## 2026-05-21 - XSS Vulnerability with dangerouslySetInnerHTML\n**Vulnerability:** XSS vulnerability by rendering strings with `dangerouslySetInnerHTML` without sanitization.\n**Learning:** Using `dangerouslySetInnerHTML` just to render newlines is a severe anti-pattern that introduces XSS risks. Adding a new sanitizer dependency should be avoided if a simple native alternative exists.\n**Prevention:** Instead of adding heavy sanitizer dependencies for simple text with newlines, split the string by `\n` and map them to text nodes interspersed with `<br/>` tags.
