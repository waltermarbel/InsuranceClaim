## 2024-05-21 - Keyboard Navigation for Hover UI\n**Learning:** Hover-revealed UI elements (e.g., elements using `opacity-0 group-hover:opacity-100`) are invisible during keyboard navigation unless paired with `focus-within:opacity-100` on the hover-revealed container, and `focus-visible:ring-*` alongside `outline-none` directly on the interactive elements to ensure visibility and usability via keyboard navigation.\n**Action:** Always include focus-within on hover containers and focus-visible on the interactive elements inside them.
