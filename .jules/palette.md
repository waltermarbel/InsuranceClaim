## 2024-10-24 - Accessibility for hover-revealed action buttons
**Learning:** In the `InsuranceSection` UI, small icon-only action buttons (like delete or remove) inside tags or list items were using `opacity-0 group-hover:opacity-100` to keep the UI clean. However, this pattern completely hid the buttons from keyboard users.
**Action:** Always pair `opacity-0 group-hover:opacity-100` with `focus-within:opacity-100` on the container element (if the button itself isn't immediately focusable when hidden) and add `focus-visible:opacity-100 focus-visible:ring-2 focus-visible:outline-none` directly to the button element. This ensures the button becomes visible and displays a focus ring when navigated to via keyboard. Additionally, never forget `aria-label` and `title` for icon-only buttons.
