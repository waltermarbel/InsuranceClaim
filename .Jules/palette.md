## 2024-06-29 - Inaccessible Hover-Reveal Actions and Missing Interactive Semantics
**Learning:** In the `TaskBoard` component, interactive elements such as task toggles, view filters, delete buttons, and context selectors systematically lacked essential accessibility (a11y) semantics (`aria-label`, `aria-pressed`) and visible focus indicators. The most severe issue was the "delete task" button, which relied entirely on hover-reveal logic (`opacity-0 group-hover:opacity-100`), making it fundamentally invisible and inaccessible to keyboard users during standard sequential navigation.
**Action:** When implementing hidden utility actions (like delete or edit icons), always ensure keyboard accessibility by pairing `group-hover` styles with explicit `focus-visible` states (e.g., `focus-visible:opacity-100 focus-visible:ring-2`). Additionally, explicitly label stateful UI toggles with `aria-pressed` and always provide `aria-label` and `title` attributes for icon-only buttons to guarantee clarity for screen-reader and mouse users.
