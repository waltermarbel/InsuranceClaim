## 2024-07-01 - Keyboard Accessibility for Hover-Revealed Actions
**Learning:** In the Inventory Dashboard, row-level actions (like the delete button) are hidden by default using `opacity-0` and revealed on `group-hover:opacity-100`. This creates a severe accessibility issue because these elements are completely invisible to keyboard-only users who navigate via the Tab key, even when the element receives focus. The specific pattern `focus-within` on the container is needed to make the hidden container appear when a child receives focus, and the child button requires `focus-visible:opacity-100` alongside ring styles to ensure it is both visible and clearly highlighted.
**Action:** Always pair `group-hover:opacity-100` with `focus-within:opacity-100` on the container of interactive elements, and add `focus-visible:opacity-100 focus-visible:ring-2 focus-visible:outline-none` directly on the focusable elements. Verify that hover-revealed elements are fully reachable and visible via keyboard navigation.
